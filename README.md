# WebStudio — GoIT HTML/CSS Homework 06

Адаптивна верстка (Mobile First, 320px / 768px / 1158px) на основі оригінального проєкту ДЗ №5.

- HTML + CSS, без JavaScript. Мобільне меню та модальна форма відкриваються CSS-перемикачами.
- Клас `is-open` для `.mobile-menu` підтримується додатково, як в умовах завдання.
- Іконки `images/icons.svg` взяті з оригінального ДЗ №5, додана тільки іконка відкриття меню.
- Фотографії команди, портфоліо та десктопний фон Hero взяті безпосередньо з оригінального ДЗ №5; назви файлів описові.
- У джерелі ДЗ №5 були тільки растрові картинки 1x. Файли `@2x` отримані збільшенням 1x, тому **не містять справжніх додаткових деталей Retina**. Для ідеального 2x потрібен експорт оригіналів із Figma.
- Планшетні й мобільні Hero-фони — кадрування оригінального `hero-bg.jpg`, окремих Figma-експортів у ДЗ №5 не було.
- Сторінка не надсилає дані форми на бекенд.

Відкрийте `index.html` у браузері або через VS Code Live Server.

## Виправлення за перевіркою GoIT

- Прямі нащадки body: header, main, footer, div#modal, div#mobile-menu.
- Семантичні кнопки відкриття модалки та мобільного меню.
- Відкриття та закриття здійснюється нативним HTML Popover API, JavaScript не використовується.
- Поповер меню підтримує клас `is-open` для перевірки.
- Контейнер базової ширини 320px; клас `.sr-only`; SVG меню 24×24.
- Браузер повинен підтримувати HTML Popover API (сучасні Chrome/Firefox/Safari).
